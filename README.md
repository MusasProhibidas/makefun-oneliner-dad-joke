A program that writes a single dad joke (65 characters): "I told my wife she should embrace her mistakes. So she hugged me." A straight-faced domestic anecdote with a double pun — "embrace" flips from figurative (accept your mistakes) to literal (hug them), and the punchline reveals that the mistake she embraces is him. The groan lands on the page, no setup or audio needed.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the joke to `out/entry.txt` and verifies it byte-for-byte (SHA-256) against `line.txt`.
